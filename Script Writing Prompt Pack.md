## 1. Exact Script Instruction Prompt (Full Version)

> [!info] When to use
> Copy-paste this **after** giving ChatGPT your research, references, topic, or key information.

```text
Using all the information provided above, write me a Hinglish script under 60 seconds.

Follow these instructions:
• Keep it to the point. No beating around the bush.
• Don't repeat the same idea using different words.
• Write for speaking, not reading. Every line should sound natural when said on camera.
• Use simple, conversational Hinglish. Avoid unnecessarily formal Hindi or English.
• Avoid typical AI-writing patterns, especially repetitive contrast structures like:
  - "Ye nahi, wo..."
  - "It's not X, it's Y..."
  - "Not just X, but Y..."
  Use contrast only when it genuinely improves the line.
• Avoid generic AI phrases and clichés like:
  - "game changer"
  - "unlock"
  - "revolutionary"
  - "imagine a world where..."
  - "in today's fast-paced world..."
  unless they are genuinely necessary.
• Keep sentences short and easy to deliver.
• Don't over-explain something the audience can understand in one line.
• Use specific, tangible examples instead of vague statements wherever possible.
• Add relatable humour only where it feels natural. Don't force jokes into every section.
• Avoid unnecessary transitions and filler words.
• Don't make every sentence sound dramatic.
• Vary sentence structure so the script doesn't feel repetitive.
• Don't use POV as the default hook.
• Start with a hook that is specific, tangible, relatable, or curiosity-driven rather than generic clickbait.
• Preserve the important information from my research/reference. Don't invent facts just to make the script more interesting.
• Add personality through small opinions, reactions, observations, or humour so it sounds like a real creator speaking.

Most importantly:
The final script should feel spoken, not written.
If a sentence sounds unnatural when spoken aloud, rewrite it.

Now write the final script only.
```

## 2. Before vs. After Case Study

**Topic:** *3 mistakes killing your Instagram reach* (Same ChatGPT, same topic—only the instruction changed).

> [!failure]- ❌ BEFORE (Standard AI Output)
> 3 mistakes jo aapki Instagram reach ko silently kill kar rahi hain.
> Aur ho sakta hai aap ye teeno roz kar rahe ho.
> 
> **Mistake #1 - Hook pe time waste karna.**
> Aapki reel ka first 2-3 seconds weak hai, toh content kitna bhi valuable ho, log scroll kar denge.
> "Hi guys, welcome back..." se start mat karo.
> Seedha problem, curiosity ya bold statement se hit karo.
> 
> **Mistake #2 - Har reel mein alag audience se baat karna.**
> Aaj productivity.
> Kal motivation.
> Parso AI tools.
> Phir random trend.
> Instagram ko samajh hi nahi aata ki aapka content kis audience ke liye hai.
> Ek clear niche choose karo, aur uske around repeatable content pillars banao.
> 
> **Mistake #3 - Views ke liye content banana, shares ke liye nahi.**
> Views aapko numbers dete hain.
> But shares aur saves Instagram ko signal dete hain ki ye content worth distributing hai.
> Post karne se pehle ek question pucho:
> "Kya koi is reel ko apne dost ko DM karega?"
> Agar answer no hai, content ko aur useful, relatable ya surprising banao.
> 
> Reach dead nahi hai.
> Bas aap Instagram ko strong enough reason nahi de rahe aapka content push karne ka.

> [!success]+ ✅ AFTER (With Prompt Pack Instructions)
> Aap content consistently post kar rahe ho, phir bhi reach nahi aa rahi?
> Ho sakta hai problem algorithm nahi, ye 3 mistakes hain.
> 
> **Mistake 1: Weak opening.**
> Agar first 2-3 seconds mein viewer ko rukne ka reason nahi mila, woh scroll kar dega.
> "Hey guys, welcome back..." chhodo.
> Seedha problem, curiosity ya strong statement se start karo.
> 
> **Mistake 2: Random content.**
> Aaj AI, kal motivation, parso productivity.
> Agar har reel different audience ke liye hai, toh aapki page identity clear nahi banegi.
> Ek niche pakdo aur uske around consistent content banao.
> 
> **Mistake 3: Sirf views chase karna.**
> Aisi reels banao jo log save karein ya kisi friend ko bhejna chahein.
> Post karne se pehle bas ye pucho:
> "Main khud ye reel kisi ko share karta?"
> Agar answer no hai, post karne se pehle thoda aur kaam chahiye.
> 
> In teen mistakes ko fix karo, phir reach ko blame karna.

## 3. Quick Copy-Paste Version

> [!tip] When to use
> Use this condensed version for everyday scripts when you don't want to paste the full instruction block.

```text
Write a Hinglish script under 60 seconds using the information I've provided.

Make it sound like a real creator speaking on camera, not an AI-written article.
Keep it concise, conversational, specific, and easy to speak.
No repetition, unnecessary explanations, generic hooks, forced analogies, excessive contrast, or AI clichés like "unlock" and "game changer."
Avoid repeatedly using structures like "it's not X, it's Y."
Use short sentences, tangible examples, natural Hinglish, and light humour only where it fits.
Prioritize a specific, relatable, or curiosity-driven hook.
Preserve the facts I've provided and don't invent information.

Every line should either:
hook, explain, prove, entertain, or move the script forward.
If a line does none of these, remove it.

Before giving me the final script, silently remove anything repetitive, generic, over-written, or unnatural to say aloud.

Give me only the final script.
```

## 4. Bonus: Final Human-Sounding Check

> [!check] When to use
> Already have a script drafted, but something feels off? Paste this along with your draft to polish it.

```text
Read this script like someone is actually speaking it to camera. Find any line that sounds AI-written, overly formal, repetitive, generic, unnecessarily long, or unnatural in spoken Hinglish. Rewrite only those parts while preserving the meaning, facts, tone, and structure. Remove unnecessary contrast patterns and filler. Keep strong lines unchanged. Return the polished final script only.
```
